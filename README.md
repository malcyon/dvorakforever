# Dvorak Forever

This addon updates your World of Warcraft keybinds to follow a dvorak keyboard layout. I grew tired of manually mapping this myself every time I installed a WoW client, so I wrote this to handle it automatically.


## How to use

Open **Options → AddOns → Dvorak Forever** and choose a layout from the dropdown. Or use chat:

| Command | What it does |
|---|---|
| `/dvorak dvorak` | Move bindings to their Dvorak positions |
| `/dvorak qwerty` | Move them back |
| `/dvorak keys` | Print the name the game gives each key you press; type it again to stop |
| `/dvorak` | Show the current layout and open the options page |
